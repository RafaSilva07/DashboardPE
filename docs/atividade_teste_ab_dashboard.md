# Atividade - Teste A/B no Dashboard de Indicadores

## 1. Introdução

O dashboard de indicadores foi criado para facilitar a análise dos dados de vendas e e-commerce. Ele apresenta informações como faturamento, lucro, quantidade vendida, categorias de produtos, regiões e períodos analisados.

O teste A/B foi pensado para comparar duas versões visuais da interface do dashboard. O objetivo é observar qual versão ajuda melhor o usuário a encontrar informações importantes de forma mais rápida, clara e organizada.

## 2. Questão 1 - Formulação do Teste A/B

### 2.1 Versão A - Layout Atual

Na Versão A, o dashboard mantém o layout atual. Os cards de indicadores aparecem no topo da tela, mostrando informações principais como faturamento, lucro e quantidade vendida. Logo abaixo ficam os gráficos, que ajudam na interpretação dos dados.

Os filtros ficam distribuídos pela tela ou próximos aos gráficos. Dessa forma, o usuário precisa observar diferentes partes da interface para filtrar os dados e interpretar os resultados.

### 2.2 Versão B - Layout com Mudança Visual

Na Versão B, os filtros principais ficam reunidos em uma barra fixa na parte superior da tela, com maior destaque visual, antes dos cards e gráficos.

Os filtros principais considerados são:

- Região;
- Categoria;
- Produto;
- Período.

Os cards principais continuam no topo da análise, mas ficam logo abaixo da barra de filtros. Assim, o usuário primeiro escolhe o recorte da análise e depois visualiza os indicadores e gráficos relacionados.

### 2.3 Hipótese do Teste

A hipótese da equipe é que a Versão B deve facilitar melhor a análise do usuário, pois os filtros ficam mais visíveis e organizados. Assim, o usuário tende a localizar as informações com menos tempo, menos cliques e maior clareza.

As hipóteses do teste são:

- H0: A mudança visual não melhora o uso do dashboard.
- H1: A mudança visual melhora o uso do dashboard.

## 3. Questão 2 - Observação e Métricas

### 3.1 Métricas Utilizadas

As métricas utilizadas para comparar as duas versões foram:

1. Tempo para localizar uma informação específica: mede quanto tempo o usuário leva para encontrar o dado solicitado.
2. Número de cliques realizados: mostra quantas interações o usuário precisou fazer até concluir a tarefa.
3. Uso correto dos filtros: verifica se o usuário conseguiu aplicar os filtros adequados para a análise.
4. Taxa de conclusão da tarefa: indica se o usuário conseguiu finalizar a atividade proposta.
5. Preferência do usuário ao final do teste: registra qual versão o usuário considerou mais fácil de usar.

### 3.2 Forma de Coleta dos Dados

A equipe pode pedir para os participantes realizarem tarefas simples no dashboard, como encontrar o faturamento de uma região específica, identificar a categoria com maior lucro, filtrar as vendas de um produto e comparar o desempenho de duas regiões.

Durante o teste, os dados podem ser anotados em uma tabela simples, registrando o tempo gasto, a quantidade de cliques e se a tarefa foi concluída corretamente.

### 3.3 Resultados Observados

A tabela abaixo apresenta dados simulados para representar a comparação entre as duas versões do dashboard.

| Tarefa | Tempo médio na Versão A | Tempo médio na Versão B | Cliques na Versão A | Cliques na Versão B | Melhor versão |
|---|---:|---:|---:|---:|---|
| Localizar faturamento por região | 48 segundos | 34 segundos | 5 | 3 | B |
| Encontrar categoria com maior lucro | 52 segundos | 39 segundos | 6 | 4 | B |
| Filtrar vendas por produto | 45 segundos | 31 segundos | 5 | 3 | B |
| Comparar desempenho entre regiões | 60 segundos | 43 segundos | 7 | 5 | B |

Com base nos dados da tabela, foram obtidas as seguintes médias:

- Média de tempo da Versão A: 51,25 segundos;
- Média de tempo da Versão B: 36,75 segundos;
- Média de cliques da Versão A: 5,75 cliques;
- Média de cliques da Versão B: 3,75 cliques.

### 3.4 Conclusão da Comparação

A Versão B apresentou melhor desempenho visual e funcional. Ela reduziu o tempo médio para localizar informações, diminuiu o número médio de cliques e deixou os filtros mais visíveis para o usuário.

Com os filtros reunidos na parte superior da tela, o usuário entende melhor onde começar a análise. Isso facilita o uso do dashboard e torna a interpretação dos indicadores mais clara.

Com base nos dados observados, a equipe aceitaria a hipótese de que a Versão B facilita melhor a análise do usuário.

## 4. Considerações Finais

O teste A/B ajudou a equipe a perceber que pequenas mudanças visuais na interface podem melhorar a experiência do usuário. No caso analisado, organizar os filtros em uma barra superior tornou o dashboard mais prático e ajudou a tornar a análise dos indicadores mais rápida e clara.
